#  Проект

## Описание

Этот проект реализует детекцию СИЗ с помощью модели YOLO (Ultralytics YOLOv8). Проект состоит из нескольких модульных файлов, которые обеспечивают следующие функции:

- **GUI (gui.py)** – основной графический интерфейс, через который можно:
  - Подключить камеру и отобразить видеопоток с наложенной детекцией.
  - Предложить анализ фотографии (выбрать изображение, провести детекцию и сохранить результат).
  - Предложить анализ видео (выбрать видео, провести детекцию на каждом кадре и сохранить результат).
  - Открыть папку с результатами анализа.

- **camera_inference.py** – отдельный скрипт для запуска только камеры. При запуске открывается окно с видеопотоком, запись видео сохраняется в папку `cam_test` в формате MP4. Для остановки видеопотока нужно нажать клавишу **ESC**.

- **predict.py** – модуль для анализа выбранных фотографий и видео.

- **Другие модули** – для обучения модели, дообучения и подготовки данных (см. другие файлы проекта).

## Требования

Для работы проекта необходимо установить зависимости из файла **requirements.txt**. В файле указаны следующие библиотеки: opencv-python и ultralytics. 

Установку необходимых библиотек можно выполнить командой:
```bash
pip install -r requirements.txt 
```
